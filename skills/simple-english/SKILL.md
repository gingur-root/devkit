# Simple English

From `agents/sdlc.md` ("Human-facing writing") and the I Have ADHD skill
(`ayghri/i-have-adhd@723af7d9`). Pragmatic mode: exact names, commands,
paths and identifiers stay as they are, even when they aren't simple words.

1. Start each section with what the reader does or gets. Background comes
   after, only when it changes what they do.
2. Number procedures. One bounded action per step, with its copyable command.
3. Use familiar words, active voice, and one point per sentence.
4. Say why once, next to the rule it explains.
5. Name each thing the same way every time.
6. Cut what doesn't change behavior: filler, repeated conclusions, history.
7. A longer document is fine when the task needs it. Include all required
   content; never shorten away a failed check or an unresolved requirement.
